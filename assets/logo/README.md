# WALTER logos – PERMANENT REGEL

Lägg de tre fasta logofilerna här:

| Fil | Innehåll | Används |
|---|---|---|
| `walter-symbol.svg` | Bara symbolen | Mobil topbar |
| `walter-wordmark.svg` | Bara ordet WALTER, solid vit | (reserv) |
| `walter-full.svg` | Symbol + wordmark | Desktop topbar |

- Byt **aldrig** ut filerna. Generera **aldrig** nya logos.
- Wordmark är solid vit. Ingen regnbågs-gradient.
- Ingen CSS-regnbåge, gradient-text eller färgfilter på WALTER.

Är filerna PNG i stället för SVG: ändra bara `src` i `index.html`.
